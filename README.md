# Python Login

## Sobre o projeto

Este é meu primeiro projeto prático em Python. Desenvolvi um programa simples de autenticação para praticar lógica de programação e estruturas de controle.

## Funcionalidades

* Solicita uma senha ao usuário.
* Compara a senha digitada com uma senha predefinida.
* Permite até três tentativas incorretas.
* Informa quando o acesso é autorizado ou bloqueado.

## Conceitos praticados

* Variáveis
* Entrada de dados com `input()`
* Condicionais `if` e `else`
* Laço de repetição `while`
* Contadores
* Interrupção de loops com `break`

## Como executar

É necessário ter Python instalado.

No terminal, execute:

```bash
python main.py
```

## Limitações de segurança

Este projeto é exclusivamente educacional. A senha está armazenada diretamente no código e não há proteção adequada para uso em sistemas reais.
